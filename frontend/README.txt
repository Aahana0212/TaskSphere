TaskSphere — consistent Slate + Emerald theme for ALL pages.

1. Keep your existing App.tsx and all TSX files unchanged.
2. Replace frontend/src/TaskSphereTheme.css with src/TaskSphereTheme.css from this ZIP.
3. Ensure App.tsx imports './TaskSphereTheme.css' AFTER './App.css'.
4. Run npm run dev and hard refresh (Ctrl+Shift+R).

This changes only CSS; authentication, localStorage and backend are untouched.
